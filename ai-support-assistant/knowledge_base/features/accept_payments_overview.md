# Accept Payments Overview - Quickteller Business

Quickteller Business offers you the ability to accept customer payments on different channels using numerous payment methods offered by Interswitch.
To get started with Accept Payment, you have two options:
Default Test Credentials:
 You can begin using 
default test credentials
. These credentials are designed for simulation in a safe environment, allowing you to explore Accept Payment's functionality without processing real payments.
Generate Integration Credentials:
 You'll need to 
generate integration credentials
 for live, production-level payment processing. These credentials ensure the security and authenticity of your transactions, providing a seamless payment experience for your customers.
Once you've chosen either of these paths and obtained the necessary credentials, you can proceed to select the most suitable method for accepting payments from the following options:
Web Checkout
